# THYNKPDF v0.2.1

A small polish release on top of v0.2.0.

## What's new
- **Clearer annotation toolbar.** The annotation toolbar now uses one consistent icon set instead of mixed text symbols.
  - Every tool has a tooltip and an accessibility label.
  - The selected tool is clearly marked, in both light and dark mode.
  - Side-panel icons are now the same size as the rest.
- **Plain-English editing messages.**
  - Signed PDFs show a single note: "This PDF is digitally signed. Editing would break the signature, so editing is turned off." The editing options are greyed out instead of repeating raw codes.
  - Text that uses fonts THYNKPDF can't safely edit shows "Some text uses fonts that can't be edited safely." The technical details are behind a collapsible "Details".

The safety rules haven't changed. Only the wording and display are different (#36).
